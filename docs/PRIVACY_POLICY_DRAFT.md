# Farm Cert – Privacy Policy draft

**Last updated:** 2026-09-21

Farm Cert is an offline study application for CCAR-P and CCDV-F practice.

## Information processed

The current application does not require an account and does not send quiz answers or attempt history to a server. Quiz content is bundled with the application. Attempt history and scores are stored locally on the user's device.

The application does not currently use advertising, analytics, location, contacts, camera, microphone, or cloud synchronization.

## Sharing

The application does not sell, share, or disclose locally stored quiz progress to third parties.

## Data deletion

Because progress is stored locally, the user can delete it by clearing the application's data or uninstalling the application from the device.
